Study Sheet — Classifiers, Ensembles & Evaluation

One-page reference for Lectures 06–11: the formulas, rules, and gotchas most likely to be tested. Pairs with the practice exam.

Lecture 06

Perceptron & Margin

  • Score z = w·x + b Correct ⟺ y·z > 0; z = 0 counts as a mistake.
  • Distance = |z| / ‖w‖; signed r = z/‖w‖. Scaling w,b by any >0 doesn't move the line.
  • Mistake update: w ← w + η·y·x, b ← b + η·y A correct point changes nothing.
  • Convergence = a full pass with no mistakes. Guaranteed (finite steps) ⟺ linearly separable; on overlapping data it never stops.
  • Margin = distance to the closest training point. Prefer the largest-margin line.
  • Gives a side only, no probability (vs. logistic regression).
Lecture 07

SVM & Kernels

  • Max margin: min ½‖w‖² s.t. y·z ≥ 1 Margin = 1/‖w‖, street width 2/‖w‖.
  • Support vectors: the points with y·z = 1 — they alone set the boundary.
  • Slack ξ = max(0, 1 − y·z): 0 safe0–1 in street1 on line>1 wrong
  • Large C → costly slack → narrow margin; small C → wider margin. C→∞ = hard margin. λ = 1/(2C).
  • Hinge loss max(0, 1 − y·z) → SVM gives no probabilities.
  • Kernel K(x,u) = φ(x)·φ(u), e.g. (x·u)² — never builds φ. Large RBF γ → overfit (short reach). Standardize first.
Lecture 08

kNN & Decision Trees

  • kNN: majority vote of the k nearest (Euclidean, standardized). Stores data, no training; use odd k.
  • Small k overfits (1-NN memorizes); large k underfits. Curse of dim: near & far distances converge.
  • Gini = 1 − Σ pₖ² Entropy = −Σ pₖ log₂ pₖ Pure node = 0; two-class max at p=0.5 (Gini 0.5, entropy 1 bit).
  • Gain = parent − Σ(child share)·(child impurity). Greedy: keep the largest-gain split, recurse.
  • Deep tree overfits (limit depth / prune). Trees need no standardization; trees are unstable.
  • kNN regression / regression tree leaf → mean of the group.
Lecture 09

Ensembles

  • Variance of an average: independent σ²/M; correlated ρσ² + (1−ρ)σ²/M → floor ρσ². Want accurate & uncorrelated members.
  • Bootstrap: N draws with replacement → ~63% in, ~37% out-of-bag (OOB tests on unseen data).
  • Bagging = deep trees (low bias, high var) voted → cuts variance.
  • Random forest = bagging + m = √D random features per split → lowers ρ. More trees never hurt.
  • Boosting = small trees in sequence → cuts bias. AdaBoost α = ½ ln((1−ε)/ε); misclassified → half the weight.
  • Gradient boosting: fit each tree to the residuals, add ν·tree. Too many stages overfit (tune on held-out).
Lecture 10

Bias–Variance & Cross-Validation

  • E[error] = bias² + variance + noise σ² More flexible → ↓ bias, ↑ variance (the tradeoff).
  • Underfit: train & held-out both high. Overfit: train low, held-out high (big gap = variance).
  • k-fold CV: each example held out once; CV = mean of K fold errors. LOOCV: K = N.
  • Recipe: CV on training → pick lowest (or one-SE: simplest within 1 SE) → refit on all training → score test set once.
  • Leakage: scaling/choosing with test info. Do every fitted step (scale, select, tune) inside each fold.

  • Accuracy =(TP+TN)/all — misleads on a rare class (always-no can score high).
  • Precision = TP/(TP+FP) Recall = TP/(TP+FN)F1 = 2·P·R/(P+R) (harmonic mean).
  • Lower the threshold → TP, FP never fall (recall never drops; precision may).
  • ROC: TPR = recall vs FPR = FP/(FP+TN). AUC = P(random + outranks random −); 0.5 random, 1 perfect.
  • Rare class: use precision/recall + PR curve; fixes = move threshold, class weights, resample (training only).
