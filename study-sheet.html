Lecture 15 · Part A, C

The MLP Architecture

  • Neuron = one logistic unit: pre-activation z = w·x + b, then an activation function. (b is the bias.)
  • Layer: z = W x + b, where W has one row per unit, one column per input. Unit j = (row j of W)·x + b_j.
  • Hidden layer learns features h = g(W₁x + b₁); the output unit scores h. Features are "hidden" because the data never show their values; training fits all weights together.
  • Batch: stack N examples as rows of X; one matrix product computes all units for all examples (bias added by broadcasting).
  • Depth = layers with weights; width = units per layer; dense / fully connected = every unit to every next unit.

Counting parameters

per layer = n_in · n_out + n_out
784→100→10: (784·100+100) + (100·10+10) = 79,510. Most params in the first layer.

Universal approximation

  • One wide-enough hidden layer can approximate any continuous function on a bounded region.
  • Does not say how many units, that training finds them, or that it generalizes — so choose size by held-out accuracy.
Lecture 15 · Part B

Activations

  • Why nonlinear? Without an activation, stacked linear layers collapse to one linear layer — same straight boundaries as logistic regression. A nonlinearity between layers stops the collapse.

  • ReLU: slope 1 where on, 0 where off; a unit with z<0 outputs 0 (is "off"). Cheap, and keeps slope 1.
  • Saturation: far from 0 sigmoid/tanh flatten (slope→0), so little gradient flows — a cause of slow learning.

  • Each loss is the negative log-likelihood, so a confident wrong answer costs the most.

Softmax & cross-entropy

p_k = e^(z_k) / Σⱼ e^(z_j)
loss = − ln( p of the true class )
  • Only the true class's probability enters the loss; others count only in the denominator.
  • Loss → 0 for a confident right answer, → ∞ as the true-class probability → 0.
z=(1,−1,2), class 3: p₃ = 7.389/10.475 = 0.705 → loss = −ln 0.705 = 0.350.
Lecture 16 · Part A, B

Backpropagation

  • Chain rule: ∂L/∂w = (∂L/∂u)(∂u/∂w) — multiply the slopes along the path.
  • Backward rule: each node multiplies the upstream gradient by its local gradient and passes it back.

Gate patterns (backward)

GateSends to each input
addthe upstream gradient, copied
multiplyupstream × the other input
ReLUupstream if input>0, else 0
used twicethe sum of both gradients

The 4-step recipe (one hidden layer)

QuantityGradient
output errorδ_o = ŷ − y
output weight w₂ⱼδ_o · hⱼ (bias: δ_o)
hidden errorδ = (W₂ᵀ δ_o) ⊙ g′(z)
hidden weight W₁[j,k]δⱼ · x_k
g′ is the activation slope (ReLU: 1 if on, 0 if off). Every gradient has the shape of its parameter. Softmax+CE output error is also p − y.
Lecture 16 · Part C, D

Gradient Check & Vanishing

Numerical check

central diff = (L(w+ε) − L(w−ε)) / (2ε)
rel. err = |g_bp − g_num| / max(|g_bp|,|g_num|)
  • Central-difference error shrinks like ε² (one-sided like ε).
  • Correct backward pass → rel. err ≈ 1e-6 or less; a bug → 0.01 or more.
  • Backprop is cheap: 1 forward + 1 backward pass for all gradients (vs 2 forward passes per weight).

Training loop

forward → loss → backward → w ← w − η·grad
  • Each step uses a mini-batch (avg its gradients). An epoch = one pass over all data = ⌈N/B⌉ steps.

Vanishing gradients

  • Each layer multiplies the error by the activation slope. Sigmoid slope ≤ 0.25, so through k layers it shrinks like 0.25^k — early layers barely learn.
  • ReLU slope = 1 where on, so it does not shrink the error.
Lecture 17 · Part A, B

SGD & Mini-Batches

  • Full gradient = mean of the N per-example gradients (gradient of an average = average of gradients).
  • Mini-batch gradient = average over B random examples — an unbiased but noisy estimate. Larger B = less noise, costlier step.
  • B = 1 is SGD; B = N is full-batch. Epoch = ⌈N/B⌉ steps.
  • B ≈ 32–256 trains fastest in wall-clock: cheap per image AND reasonably accurate; many cheap noisy steps beat a few exact ones.

Learning rate

  • Too small → slow; too large → jitter or dead ReLUs (η=2.0 killed 125/128 units → no better than chance).
  • Noisier gradients (smaller batch) need a smaller η.
  • Schedule: start η large, lower it near the bottom. Step decay = ÷10 when the epoch-mean loss stalls. Judge by the epoch-mean loss.
Lecture 17 · Part C, D

Momentum & Adam

Momentum

v ← ρ·v + g, then w ← w − η·v
  • Agreeing gradients add up; flipping gradients cancel → fast along a valley, damped across it.
  • Steady g → velocity grows toward 1/(1−ρ) × g, so momentum acts like a larger η (ρ=0.9 → ~10×).

Adam

m = avg of gradients · s = avg of squared gradients
m̂ = m/(1−β₁ᵗ), ŝ = s/(1−β₂ᵗ) (bias correction)
w ← w − η · m̂ / √ŝ
  • Dividing by √ŝ gives each weight its own step size. Bias correction fixes the start at 0.
  • At t=1: m̂=g, ŝ=g², so every weight moves by exactly η against the sign of g (size cancels).
  • Defaults β₁=0.9, β₂=0.999, η=0.001.

Choosing

  • Adam (η=0.001) = good default, little tuning. SGD + momentum 0.9 + schedule still strong. Lower η when loss stalls.
How to solve · worked recipes

Solving the Numerics

Forward pass (find ŷ)

  1. Hidden pre-acts z = W₁x + b₁ (each unit = its row · x + its bias).
  2. Activation h = ReLU(z) (negatives → 0 = "off").
  3. Output z_o = w₂·h + b₂.
  4. Squash: ŷ = σ(z_o) = 1/(1+e^−z_o).

Softmax loss

  1. Exp each score, sum them.
  2. p_true = e^(z_true)/sum.
  3. loss = −ln(p_true).

Backprop gradient

  1. Run the forward pass first (store z, h, ŷ).
  2. δ_o = ŷ − y.
  3. Output weight = δ_o · h; hidden error δ = (W₂ᵀδ_o) ⊙ g′(z); hidden weight = δ · x.

Gradient check

  1. Central diff (L(w+ε) − L(w−ε))/(2ε).
  2. Rel. err |g_bp − g_num|/max(|·|); ≤1e-6 ok, ≥0.01 bug.

Momentum (per step)

  1. v ← ρ·v + g (update v first).
  2. w ← w − η·v.

Adam first step (t=1)

  1. m̂ = g, ŝ = g².
  2. w ← w − η·g/√(g²) = w − η·sign(g).

Steps & time

steps/epoch = ⌈N / B⌉ · epoch time = (cost per image)·N
