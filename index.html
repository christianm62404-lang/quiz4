Writing SQL Functions That Return Info

The quiz is entirely code-writing. Each problem asks you to CREATE a function with a given argument type and return type, compute a value, format it to the required precision, and handle the edge cases exactly. This guide drills that: declaring the right variables and types, reading data with aggregates, returning NULL vs a sentinel like -1.00, and rounding to the return type — with full worked solutions (PostgreSQL / PL-pgSQL).

Model problem: a function taking dept_name VARCHAR(50) that returns the % difference between MAX and MIN salary (of the lower one), RETURNS DECIMAL(5,2) — NULL if the department does not exist, −1.00 if it has no employees.
Assumed schema (used in every problem):
departments(id INT PK, name VARCHAR(50)) employees(id INT PK, first_name VARCHAR(50), last_name VARCHAR(50), title VARCHAR(50), salary DECIMAL(10,2), department_id INT -> departments.id, manager_id INT -> employees.id)
